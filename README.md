# -Metodo-de-Ordenamiento-de-Burbuja-

ALUMNO: Nathan Hazael Merenciano Hernandez
4to Cuatrimestre Grupo C

En esta practica se implementaran dos versiones del algoritmo de ordenamiento burbuja en Java para comparar su funcionamiento

Burbuja normal: recorre el arreglo completo en cada vuelta, aunque ya esté ordenado.
Burbuja mejorado: usa una bandera (variable boolean) para saber si hubo intercambios en una vuelta. Si no hubo ninguno, el arreglo ya está ordenado y el ciclo se detiene antes.
